# Stage 1 front-end changes

It holds names, line numbers and counts only: no code, query text or data. Line numbers are lines of the module text as the model keeps it (`code/<module>.txt`).

| SQL Server driver | Microsoft ODBC Driver 18 for SQL Server | SQL Server | Encrypt the connection; trust the server certificate only on a private network |
